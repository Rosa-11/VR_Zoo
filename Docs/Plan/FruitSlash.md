# Fruit Slash 第一版实现方案

## 概要

- 新增 VR 切水果小游戏“切水果：长颈龙与史前果实”的第一版实现方案。
- 第一版只在 `Assets/Scenes/LanTest.unity` 中做功能测试，不接入 `Scene1.unity`。
- 剧情和 Timeline 暂不真正接入；只预留开始、完成、阶段切换等公开方法和事件。
- 切割表现采用“预制半果替换”：不做运行时 Mesh Slicing，光刃轨迹穿过果实碰撞盒即算切中，然后隐藏完整果实并生成两半替代物、果汁、火花和音效。
- 暂时不实现计分UI，留出接口，使用Debug.Log暂时替代

## 玩法目标

- 玩家双手握持虚拟的“光芒蕨叶刃”，通过手臂挥动切开长颈龙抛出的史前果实。
- 不限制挥刀方向，横切、竖切、斜切都有效；只要光刃轨迹穿过果实碰撞盒即判定成功。
- 没有传统失败概念，系统按斩切数量和积分推进阶段，并通过动态放缓降低挫败感。
- 本小游戏积分只用于切水果内部反馈，与接礼物积分独立统计。

## 模块结构

第一版新增 `Assets/Scripts/FruitSlash/` 自包含玩法模块，建议包含以下类型。

### `FruitSlashBlade`

- 挂在左右手光芒蕨叶刃上。
- 每帧采样刀刃上一帧和当前帧的位置，形成挥刀线段。
- 使用线段/capsule sweep 检测果实碰撞盒。
- 同一帧或同一次挥刀中记录已命中的果实，避免重复结算。
- 支持刀光强化：
  - 判定半径扩大。
  - 刀光宽度增加。
  - 材质亮度或粒子拖尾增强。
- 对外提供：
  - `SetEmpowered(bool empowered, float duration)`
  - `SetHitRadiusMultiplier(float multiplier)`

### `FruitSlashFruit`

- 挂在完整果实预制体上。
- 保存果实类型、基础分值、是否珍稀、是否快速、是否七彩巨大果串、当前切击次数和是否已被结算。
- 接收 `FruitSlashBlade` 的切中通知。
- 普通果实切中后：
  - 标记为已切中。
  - 停止完整果实物理运动。
  - 隐藏或回收完整果实。
  - 生成对应半果占位物。
  - 播放果汁、火花和音效。
  - 通知 `FruitSlashDirector` 和 `FruitSlashScoreController` 结算。
- 七彩巨大果串切中后：
  - 累计切击次数。
  - 每次切击播放更强反馈。
  - 第 3 次切击才完成最终结算。
- 完整掉落到地面时：
  - 标记为失误。
  - 通知 `FruitSlashDirector` 更新动态难度统计。
  - 回收或延迟清理果实。

### `FruitSlashDirector`

- 负责小游戏整体流程，不直接承担 UI 或切割判定。
- 管理阶段：
  - 教学阶段：斩切数量 0-5 颗。
  - 进阶阶段：斩切数量 6-18 颗。
  - 稳定阶段：斩切数量 19 颗及以上。
- 管理波次：
  - 根据阶段决定每波果实数量、间隔、速度、落点范围和轨迹类型。
  - 根据动态难度状态临时覆盖下一波参数。
- 管理特殊刷新：
  - 每 20 颗普通果实后随机刷新 1 个珍稀果实。
  - 达到配置阈值后生成七彩巨大果串。
- 管理长颈龙表现：
  - 第一版只需要占位模型或空对象。
  - 预留 `Animator` 参数，例如 `Throw`、`ScratchHead`、`Cheer`。
  - 不接入正式剧情 Timeline。
- 对外提供：
  - `StartGame()`
  - `StopGame()`
  - `SpawnNextWave()`
  - `ForceSpawnRainbowBunch()`

### `FruitSlashScoreController`

- 独立统计切水果小游戏分数。
- 负责基础积分、连斩奖励、多斩奖励、珍稀果实奖励和终极奖励。
- 驱动世界空间计分 UI、飘分 UI 和连斩提示。
- 分数定格后不再接受普通果实结算。
- 对外提供：
  - `ResetScore()`
  - `AddFruitScore(FruitSlashFruit fruit, int sameSwingCutCount)`
  - `CompleteRainbowBunch()`

### 配置类型

建议新增以下配置类型，便于 Inspector 调参。

- `FruitSlashFruitType`
  - `FlameEgg`
  - `GoldenFan`
  - `ConeFruit`
  - `Rare`
  - `Fast`
  - `RainbowBunch`
- `FruitSlashStageType`
  - `Tutorial`
  - `Advanced`
  - `Stable`
- `FruitSlashFruitConfigSO`
  - 果实类型。
  - 基础分值。
  - 完整果实预制体。
  - 半果预制体。
  - 果汁 VFX。
  - 火花 VFX。
  - 专属音效。
  - 基础速度范围。
  - 轨迹高度范围。
  - 是否允许作为随机普通果实出现。

## 占位资源方案

第一版不处理正式果实建模，全部使用 Unity 基础 3D Object 拼接。

- 完整果实：
  - 使用两个 `Sphere`、`Capsule` 或 `Cylinder` 拼成一个根节点。
  - 根节点挂 `Rigidbody`、`Collider` 和 `FruitSlashFruit`。
  - 子物体只负责视觉。
- 半果：
  - 使用两个基础 3D Object 拼成左右两半或上下两半。
  - 切中后生成两个半果刚体，沿切割方向的法线两侧弹开。
  - 半果生命周期结束后回收或销毁。
- 视觉区分：
  - 火焰蛋：红橙色，占位火花粒子。
  - 金扇子果：金黄色，占位金色粒子。
  - 球果：棕绿色，碎屑粒子。
  - 珍稀果实：彩色光晕材质或外圈粒子。
  - 快速果实：拖尾更明显，速度略快。
  - 七彩巨大果串：多个彩色球体拼接成一串。

## 阶段规则

### 教学阶段：斩切数量 0-5 颗

- 每波 1 颗火焰蛋。
- 飞行速度极慢。
- 轨迹为平缓抛物线。
- 落点固定在玩家正前方。
- 切中后播放火花特效和基础音效。

### 进阶阶段：斩切数量 6-18 颗

- 每波 1-2 颗。
- 波次间隔 1 秒。
- 果实类型开始随机出现。
- 飞行速度提高。
- 轨迹加入轻微起伏。
- 落点扩展到玩家左右 1.2 米范围。
- 偶尔出现 2 颗果实同时飞行。
- 切中后增强果汁飞溅和欢呼声，开始触发连斩反馈。

### 稳定阶段：斩切数量 19 颗及以上

- 每波 2 颗。
- 波次间隔 0.8 秒。
- 飞行速度保持中等。
- 轨迹为多样化抛物线，偶尔有轻微转折。
- 落点覆盖玩家左右 1.5 米内的舒适挥击范围。
- 果实类型随机出现。
- 偶尔出现快速果实，速度略快并附带刀光引导。
- 达到七彩巨大果串触发条件后，生成七彩巨大果串并进入收尾。

## 动态难度

系统实时统计玩家最近表现，用于防挫败调节。

- 统计项：
  - 最近 10 秒内完整落地的果实数量。
  - 连续失误次数。
  - 连续无切中波次数。
  - 连续成功切中次数。
- 触发放缓：
  - 连续失误次数 >= 3。
  - 或连续 2 个波次无切中。
- 放缓表现：
  - 长颈龙触发 `ScratchHead` 动画参数。
  - 下一波强制只抛 1 颗果实。
  - 抛物线变高。
  - 滞空时间增加。
  - 速度降低到当前阶段的安全值。
- 恢复节奏：
  - 玩家连续 3 次成功切开果实后，恢复当前阶段的正常波次参数。

## 积分规则

### 基础积分

- 火焰蛋：15 分。
- 金扇子果：20 分。
- 球果：18 分。

### 连斩奖励

- 1 秒内连续切中果实计为连斩。
- 连斩数 1-4 次：每次额外 8 分。
- 连斩数 5-8 次：每次额外 12 分。
- 连斩数 >= 9 次：每次额外 18 分，并触发刀光变亮和欢快打击乐升级。

### 多斩奖励

- 一次挥刀轨迹同时切开 2 颗或以上果实时触发。
- 播放 `Juice Splash!` 提示和果汁四溅特效。
- 额外积分建议第一版按 `(同刀切中数量 - 1) * 10` 计算，后续可在 Inspector 调整。

### 珍稀果实奖励

- 每 20 颗普通果实后随机刷新 1 个珍稀果实。
- 切中珍稀果实获得 50 分。
- 触发临时“刀光强化”效果，持续 5 秒。
- 刀光强化期间：
  - 蕨叶刃刀光变宽。
  - 斩切判定范围扩大。
  - 切中反馈音效更亮。

### 终极奖励

- 七彩巨大果串需要连续挥击 3 次。
- 第 3 次切中后获得 150 分。
- 播放果汁雨特效。
- 积分统计定格。
- 广播小游戏完成事件，预留给后续最终剧情对话使用。

## 事件预留

事件沿用项目现有 `GameManager.Event.Broadcast` 模式。

- `"FruitSlash.Started"`：小游戏开始。
- `"FruitSlash.StageChanged"`：阶段切换。
- `"FruitSlash.FruitCut"`：果实被切中。
- `"FruitSlash.ComboChanged"`：连斩数变化。
- `"FruitSlash.Completed"`：七彩巨大果串完成，小游戏结束。

这些事件第一版只做功能预留，不在本阶段实际驱动 Timeline。

## `LanTest.unity` 接入方式

仅在 `Assets/Scenes/LanTest.unity` 中搭建测试环境。

- 放置 `FruitSlashDirector`。
- 放置左右手光刃测试对象，并挂载 `FruitSlashBlade`。
- 放置果实生成点和玩家前方落点范围。
- 配置对象池或临时预制体引用。
- 放置长颈龙占位对象：
  - 可以是空物体。
  - 可选挂 Animator。
  - 只预留 `Throw`、`ScratchHead`、`Cheer` 等参数。
- 使用基础 3D Object 拼接完整果实和半果预制体。

明确不做以下接入：

- 不修改 `Scene1.unity`。
- 不改现有剧情 Timeline。
- 不接入 `SlingshotSignal`。
- 不触发正式剧情流程。

## 编译自查

实现者交付前只需要保证 Unity Console 无编译错误。

- 新增脚本能通过 Unity 编译。
- `LanTest.unity` 所需组件字段没有明显空引用风险。
- 新增事件、枚举、配置类型命名一致。
- 不修改 `Scene1.unity`、剧情 Timeline 或正式剧情接入逻辑。

Play Mode 体验、手感、节奏、反馈效果由项目负责人在 `LanTest.unity` 中验证。

## 假设

- 第一版不引入 Mesh Slicing 插件，也不运行时重建 Mesh。
- 果实和半果全部使用 Unity 基础 3D Object 占位，正式模型、材质和动画后续替换。
- 切水果分数与接礼物分数完全独立，不产生负分或失败状态。
- 剧情系统只保留接口和事件，不实际运行 Timeline。
